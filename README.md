# موسم دريم ليج — نسخة حقيقية Full-Stack

## ما الذي أصبح حقيقيًا؟
- Backend بـ Node.js + Express.
- قاعدة بيانات SQLite حقيقية.
- تسجيل/دخول بحسابات محفوظة في قاعدة البيانات.
- كلمات المرور يتم تخزينها كـ bcrypt hash.
- جلسات دخول عبر HTTP session.
- صلاحيات Admin حقيقية.
- الأدمن ينشر أخبارًا من لوحة التحكم ويرفع صورة من الجهاز.
- حذف الأخبار للأدمن.
- المباريات والبطولات تُقرأ من قاعدة البيانات.
- مساعد AI حقيقي اختياري عبر OpenAI API.

## تشغيل المشروع
1. ثبّت Node.js 20 أو أحدث.
2. فك الضغط.
3. انسخ `.env.example` إلى `.env`.
4. غيّر `SESSION_SECRET` إلى قيمة عشوائية طويلة.
5. نفّذ:
   npm install
   npm start
6. افتح:
   http://localhost:3000
